# Operator X Console

A thousand years after the Great Fall, humanity is preparing to leave Earth aboard the ship that nearly destroyed it.

Within the ship's Artifact, millions share an existence beyond the lives they once knew. Joining them requires a state of consciousness few could attain until A-HAVA was built from the old world's surviving VR technology. Guided by AI and human operators, the remaining people work through simulated lifetimes so they too can integrate into the Artifact. Only then can the ship depart.

Operator X is the last operator. The work comes naturally—until X is assigned Prisoner 285, a person driven by chaos, violence, and addiction.

X walks through the prisoner's recorded lives, searching for a way forward. As the prisoner's world moves on, the other operators reach their limits and retreat into the Artifact. Eventually, only X, the robots, and one unfinished life remain.

**Can X guide the last person into the Artifact before losing the way back?**

Told through Operator X's recovered console, *The Many Lives of Operator X* follows humanity's journey into the unknown, X's search for the past, and the lives X must enter along the way.

The recovered console contains Operator X's personal journal and documents received while working as an operator. Records become available as X discovers them, so follow the timeline to investigate the story.

## How to investigate

Approach the recovered journals and documents like a detective arriving after the events. Who was Operator X before? What was X's connection to the Institute? Did X complete the mission? Choose the mysteries you want to investigate.

Not every detail is a clue. Some records offer evidence; others add story, atmosphere, or trivia. You decide what's interesting. As more journal entries and documents are uncovered, new evidence may shift the questions you want to pursue.

## Start in an AI chat

1. Choose **Code → Download ZIP** on this GitHub page.
2. Attach the ZIP to a fresh AI chat.
3. Say **“Open the console.”**

The ZIP is a snapshot of the console files, not an application to install. If the AI needs more direction, say: **“Open the ZIP, read operator-x-week-one.txt, and run the console.”**

If your chat cannot read ZIP files, extract the archive and attach `operator-x-week-one.txt` and the images from `media/`. Start a fresh conversation so earlier story discussions do not influence the experience.

## Use the console

Once the console opens, say **Open journal**. You can also:

| Command | What it does |
| --- | --- |
| **Continue** | Opens the next unread journal entry. |
| **Open document** | Opens a newly available document, or asks which one you mean. You can name a document directly. |
| **Ask a question** | Answers from the records available at your current point in the story. |

Documents become available as the journal progresses. Previously available documents can be opened again by name. The console follows X's discoveries; it does not make every record available at the start.

When opening a document, the AI should use its in-chat document view when available. It should display supplied images in the chat, or open the supplied image in a browser if chat display is unavailable. If it cannot retrieve the image either way, it should show:

> **CONSOLE ERROR · FILE UNAVAILABLE**
>
> Unable to retrieve the requested image.

## Save and resume

1. **Get a bookmark for your current place.** Say **Save my position** and keep the code the console returns. It records your reading position and which journal entries you have read; it is not an account login or a server save.
2. **Resume from a bookmark.** In a new chat, attach the same console package and send:

```text
Resume the Operator X console from this bookmark. Use the instructions and records in the attached package. Show my current status and wait for my choice.

[paste your saved code here]
```

## Use a local AI tool

Extract the ZIP and open its folder in your AI tool. Start a fresh conversation and say **“Open the console.”** The included `AGENTS.md` provides startup guidance for tools that support it.
